# TopHat-Tracker
Notifies you of tophat questions on desktop \n
Depends on puppeteer and node-notifier \n
Navigate to the course page where it shows "unanswered questions" and paste the url \n
The first time you run this code a window will open where you need to sign in to tophat. After that change the value of "LoggedIn" to True and the window will not need to be open while running the code
